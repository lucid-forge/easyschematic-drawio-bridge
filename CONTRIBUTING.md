# Contributing

Thank you for helping improve EasySchematic Draw.io Bridge.

## Before opening an issue

- Confirm the problem still occurs in the latest `main` branch.
- Test in a recent Chrome or Edge release.
- Indicate whether the EasySchematic API was available or the application was in local mode.
- For rendering problems, include the device name, selected dimensions, browser, and Draw.io version.

Do not include private inventory data, credentials, API keys, or confidential diagrams.

## Pull requests

Keep changes focused and preserve the dependency-free, single-page architecture unless a broader change has a demonstrated benefit.

Manually verify light and dark themes, clipboard output, `.drawio` export, and local-library import/export before submitting a pull request.

Use clear English for interface text and commit messages.
