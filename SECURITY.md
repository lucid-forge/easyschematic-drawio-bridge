# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's **Report a vulnerability** feature when it is enabled for this repository. Do not publish credentials, private device inventories, or proof-of-concept data in a public issue.

## Data handling

The application is client-side only. It stores device definitions and preferences in the browser and contacts the public EasySchematic templates endpoint. It does not require or accept an API key.

Imported files are parsed locally. Users should only import Draw.io libraries or JSON files from sources they trust.
